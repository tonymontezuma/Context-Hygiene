# Caso anonimizado

Dados históricos fornecidos pelo idealizador do projeto; não houve acesso aos artefatos originais nesta V1. A métrica é **skills marcadas como nunca usadas**, não skills instaladas, tokens, preço ou velocidade.

| Origem | Antes | Depois |
|---|---:|---:|
| User | 121 | 26 |
| Synced | 16 | 6 |
| Plugin | 252 | 17 |
| Total | 389 | 49 |

Redução de 340 itens: `(389 − 49) / 389 × 100 = 87,4036…%`, arredondada para **87,4%**.

Este caso ilustra uma auditoria possível; não estabelece causalidade sobre tokens ou qualidade, faixa ideal, meta, score ou promessa. Outra configuração pode estar adequada com muito mais itens ou nenhuma redução. Stack, dependências e testes funcionais determinam sucesso.

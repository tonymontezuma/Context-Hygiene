02 / UM PROCESSO, SEIS ETAPASSEM LIMPEZA EM MASSA

Meça. Entenda.
Mude com critério.

Entender antes de recomendar. Avaliar escopo, ativação e Project Relevance. Manter tudo pode ser a decisão certa.

  1. 01
    baseline

    Comece pelo seu projeto.

    Agente, versão, tarefas essenciais e evidência inicial. A detecção usa o que você fornece; na dúvida, perguntamos.

    ⌁
  2. 02
    inventory → context map

    Mapeie o que cada agente carrega.

    WHAT IS IT / WHERE DOES IT LIVE / WHEN IS IT USED. Instalado, listado e carregado são coisas diferentes.

    ⊞
  3. 03
    scope → activation → relevance

    Avalie o que faz sentido aqui.

    Examine Duplication, Conflict, Overlap, Stale e Capability Bloat conforme a necessidade real do projeto.

    ≋
  4. 04
    recomendação → uma mudança

    Escolha uma mudança reversível.

    Entenda evidência, impacto esperado, dependências, escopo e rollback. Você decide e aplica.

    ↗
  5. 05
    before / after → keep / revert

    Meça, teste e decida.

    Compare a mesma medida e teste a capacidade em todos os agentes afetados. Mantenha ou reverta.

    ✓
  6. 06
    relatório → feedback opcional

    Termine com evidências.

    Resultados e pendências claros. Depois, escolha se quer preparar métricas não sensíveis para compartilhar manualmente.

    ≡

WHAT / WHERE / WHEN

Um modelo para usar em cada projeto.

WHAT IS IT?

Skill · Agent · MCP · Plugin · Hook · Rule · Memory

WHERE DOES IT LIVE?

Global / User · Project · Directory · Session

WHEN IS IT USED?

Always · Conditional · Explicit · Disabled · Unknown

Multiple / cross-agent: identifique fontes compartilhadas e instruções conflitantes. Preserve repetições necessárias a outro agente. Candidato à remoção é recomendação, não estado de ativação.

05 / SEM CAIXA-PRETA

Vale saber.

Isso reduz 87,4% dos meus tokens?+

Nenhum percentual de economia de tokens foi medido. Os 87,4% históricos descrevem a contagem de skills nunca usadas. Tokens, tempo e dinheiro exigem medições próprias e comparáveis.

Quais agentes posso auditar?

A V1 inclui adapters documentais para Claude Code, Codex, Google Antigravity e Cursor, com modo Multiple. É suporte arquitetural; instalação nativa e auditorias completas nos quatro hosts ainda precisam ser testadas.

O coach desliga ou apaga algo sozinho?+

Não. Ele analisa somente as evidências fornecidas por você, sugere uma mudança reversível por vez e aguarda sua aplicação. Não há acesso direto ao computador nem execução automática de alterações.

O que preciso compartilhar?+

Compartilhe versão, tarefas essenciais e o menor inventário ou screenshot relevante. Oculte segredos antes. Métricas de tokens ausentes ficam desconhecidas. As políticas do host continuam valendo. Privacidade.

As métricas da auditoria são coletadas?

Desligadas por padrão. Após o relatório, você pode optar por preparar números não sensíveis, revisar e compartilhar manualmente. Sem coletor ou envio automático. O GA4 já existente no site é separado das métricas de auditoria.
